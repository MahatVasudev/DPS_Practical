# Problem 1

## E-COMMERCE CUSTOMER BEHAVIOUR, SEGMENTATION & CHURN

This is a churn prediction and risk problem, and also a customer segmentation problem as well.

We want to solve this problem for an <u>An Online Retailer</u>

**Who expects us to solve these problems:**

- Understand user behavior and segment them.
- Understand user behavior for churn and risk of becoming inactive

**Impact on solving this problem:**

By solving this problem we

- can understand and find any **relation with segments and churn**.
- can analyze root causes for churn. And act upon them accordingly.
- can use better targeted marketing on products based on the segmentation.

**Ideal Outcome**

The ideal outcome would be

- to get clear segments of customers without too much overlap.
- to get clear understanding of the parameters and factors leading to churn.

**Assumptions**

According to data-set provided, it lacks a specified churn column, therefore we would have to define churn ourselves

**Method of solving**

We would create separate data-sets for churn prediction and segmentation
